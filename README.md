# Tracked Out

**Send it. We'll do the math.** Ski and snowboard tracking for iPhone: vertical, speed, turn
counts and a map of every lap, plus a read on what you did well and where you're losing time.

[trackedout.app](https://trackedout.app)

---

## About this repo

The Tracked Out marketing site — one page, statically built, no backend.

## Local development

```bash
npm install
npm run dev
```

`npm run build` produces `dist/`. `npm run typecheck` runs `tsc --noEmit`.

If the map ever falls back to its placeholder in dev for no obvious reason, Vite's dependency
cache has gone stale: `rm -rf node_modules/.vite` and restart.

## Project layout

```
design/           the handoff, untouched, plus the original asset exports
  HANDOFF.md      the spec
  review-options.html   three treatments of the reviews section (not wired in)
scripts/          one-off asset pipeline, run by hand
src/app/map/      everything Mapbox: config, loader, layers, lifecycle hooks
src/app/components/sections/   one file per section of the page
src/styles/       tokens (theme.css), component CSS, Tailwind entry
```

## Environment

Both variables are optional. The site builds and runs without either.

| Variable | Effect if unset |
|---|---|
| `VITE_GA_MEASUREMENT_ID` | No analytics script is injected. |
| `VITE_MAPBOX_TOKEN` | All three maps fall back to their styled placeholders. |

Set them in a local `.env` (gitignored) and as GitHub Actions secrets for deploys. See
`.env.example`.

**Neither is a secret.** Vite inlines every `VITE_*` variable into the built JavaScript, which
is served publicly from GitHub Pages. The Actions secret keeps the value out of *this repo*, not
out of the *bundle*. That is normal and correct for a Mapbox `pk.*` token; spend is protected by
URL restrictions and a monthly limit set in the Mapbox account, not by hiding the string.

## Assets

`design/assets/` holds the untouched handoff exports. `src/assets/` holds the web-ready versions
the app imports, generated by:

```bash
npm i --no-save sharp && node scripts/build-assets.mjs
```

That step matters. The handoff's logo SVGs are traced outlines (~3.1MB each, still 376KB gzipped
after precision reduction) and the PNGs are exported at 2–5x their display size. The script takes
the bundle from 8.4MB to ~418KB. Re-run it whenever an asset is re-exported.

**The two logo SVGs are gitignored** — 6MB of traced outlines in every clone, for files nobody
opens. Their generated `src/assets/logo-*.webp` are committed, so the site builds fine without
them; you only need the originals back in `design/assets/` to re-run the logo half of the script.
They are in the original Claude Design handoff bundle.
